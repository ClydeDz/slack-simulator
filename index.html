Why Use Slack Simulator?

Fast Iteration

No ngrok, no OAuth dance, no network dependencies. Just run yarn dev and start developing against it immediately.

Multi-User Testing

Switch between mock users instantly to test multi-user conversations and bot interactions from any perspective.

Deterministic Resets

Wipe your workspace back to a clean seed state with one click. Perfect for reproducible testing and scenario scripting.

Persistent State

SQLite-backed persistence keeps your workspace state across sessions. Reset anytime to start fresh.

Offline Capable

Work on planes, trains, or customer sites without internet. Your development environment travels with you.

Full Debugging

Inspect Events, Interactivity payloads, and Web API calls in real-time. Built-in logs and database inspector included.
